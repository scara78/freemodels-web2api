# Security policy

## Supported versions

This project is experimental. Security fixes are applied only to the latest
commit on the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature under the
repository's **Security** tab. Do not publish secrets, working abuse payloads,
or personally identifiable information in a public issue.

Include the affected commit, impact, local reproduction steps, and a suggested
mitigation when known. Do not test findings by generating high request volume
against FreeModels.pro or any third-party provider.

## Scope

Reports about this adapter's validation, authentication, request handling,
dependency use, or accidental data disclosure are in scope. Vulnerabilities in
third-party services should be reported to those services' operators.
